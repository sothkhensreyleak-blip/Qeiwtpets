# Qeiwtpets

Pets that float around you, level up and give potion effects.

## Requirements
- Paper 26.2
- Java 25

## Commands
- `/pets` - open the pets menu
- `/pets reload` - reload config and pets
- `/pets givexp <player> <pet> <amount>` - give pet XP (admin)

## Create a pet
Copy a file in `plugins/Qeiwtpets/pets/`, edit it, then run `/pets reload`.

## Build
```
mvn package
```
The jar is created in `target/`.
